## 4. Nội dung các bài Lab

### Lab 08 – JavaScript 1: Language Foundations

Thực hành các kiến thức nền tảng của JavaScript:

- Cách nhúng JavaScript vào HTML.
- Khai báo biến và sử dụng các kiểu dữ liệu.
- Làm việc với String, Date, Math và Array.
- Xây dựng và sử dụng hàm JavaScript.
- Tạo và thao tác với Object.
- Sử dụng Browser Console để kiểm tra mã nguồn.

**Số bài thực hành:** 11 Exercise.

### Lab 09 – JavaScript 2: DOM and Events

Thực hành thao tác với các phần tử HTML và xử lý sự kiện:

- Truy xuất các phần tử thông qua DOM.
- Thay đổi nội dung và thuộc tính HTML.
- Tạo, thêm và xóa phần tử.
- Xử lý các sự kiện click, mouseover và mouseout.
- Sử dụng Chrome DevTools để gỡ lỗi.
- Làm việc với biểu mẫu và kiểm tra dữ liệu đầu vào.

**Số bài thực hành:** 8 Exercise.

### Lab 10 – JavaScript 3: jQuery

Thực hành sử dụng thư viện jQuery:

- Tích hợp thư viện jQuery vào website.
- Sử dụng Basic Selectors và Advanced Selectors.
- Xử lý sự kiện chuột bằng jQuery.
- Thêm và thay đổi các phần tử DOM.
- Tạo hiệu ứng Fade, Slide và Animation.
- Thực hiện GET Requests.
- Xử lý phản hồi bằng jqXHR.

**Số bài thực hành:** 10 Exercise.
