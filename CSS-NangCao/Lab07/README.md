# LAB 07 – ADVANCED CSS: LAYOUT

## 1. Giới thiệu

Lab 07 – Advanced CSS: Layout là bài thực hành về thiết kế và bố trí giao diện website bằng HTML và CSS.

Trong bài lab này, sinh viên thực hành các kỹ thuật định vị phần tử, xây dựng bố cục nhiều cột, thiết kế giao diện responsive và tạo các hiệu ứng chuyển động cho website.

## 2. Mục tiêu

- Hiểu cách hoạt động của Document Flow.
- Sử dụng Positioning để định vị các phần tử.
- Thực hành Float và Clear.
- Xây dựng bố cục hai cột và ba cột.
- Sử dụng Media Queries để thiết kế Responsive.
- Thực hành CSS Transform và Transition.
- Sử dụng CSS Filters và Animations.
- Làm quen với Bootstrap trong thiết kế giao diện.

## 3. Công nghệ sử dụng

- HTML5
- CSS3
- Bootstrap
- Visual Studio Code
- Google Chrome
