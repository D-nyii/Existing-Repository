# CSS-NangCao – Lab 07

Thư mục này bổ sung Lab 07 vào repository hiện có, không tạo repository mới.

## Cấu trúc

- `index.html`: trang giới thiệu CSS nâng cao.
- `Lab07/index.html`: danh sách 19 Exercise.
- `Lab07/Exercise01` đến `Exercise19`: trang chi tiết từng bài.
- `Lab07/images`: hình ảnh được cung cấp trong ZIP gốc.
- `Lab07/bootstrap`: thư viện Bootstrap được cung cấp.

## GitHub Pages

Sau khi commit lên nhánh `main` và Pages được triển khai từ thư mục gốc repository:

- Trang CSS-NangCao: `/Existing-Repository/CSS-NangCao/`
